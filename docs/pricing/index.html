Questions
How can prices be below the provider's list price?

We commit to large token volumes with providers and inference hosts, which earns wholesale rates. We keep a thin slice of that discount and pass the rest to you. Where we have no volume agreement, you pay exactly list price — never more.

Is there any fee besides the token price?

No. Routing, failover, the unified API, dashboards, and logs are included. The only exception is BYOK traffic, which carries a flat 3% fee since the tokens are billed by your provider, not us.

Do prices track provider price changes?

Yes — when a provider cuts prices, the axis price drops the same day. When a provider raises prices, existing prepaid credits keep their original rate for 30 days.

What happens to my prompts and outputs?

By default we retain metadata (token counts, latency, status) but not prompt or completion content. You can enable logging per key for debugging, or enforce zero-retention routing that only uses providers with matching policies. See Privacy.

Can I set spend limits for my team?

Yes — budgets and rate limits apply per API key, per project, and per organization, with webhook alerts at thresholds you choose.
